# Robot - Модульная система загрузки рыночных данных

## Описание

Система для загрузки и сохранения рыночных данных из TInvest API в PostgreSQL.  
Реализована компонентная архитектура для легкого масштабирования и добавления новых инструментов.

## Архитектура

### Компоненты

1. **Data Provider** (`components/data_provider/`)
   - Получает данные из TInvest API
   - Поддерживает batch запросы для нескольких инструментов
   - Маппит ответы API в типизированные схемы

2. **Database** (`components/database/`)
   - Сохраняет данные в PostgreSQL
   - Автоматически создает таблицы при инициализации
   - Поддерживает batch вставку для производительности

3. **Orchestrator** (`components/orchestrator/`)
   - Координирует загрузку данных
   - Управляет временными интервалами
   - Обрабатывает ошибки и логирует процесс

### Общие модули

- **Common** (`common/`)
  - `logging.py` - настройка логирования
  - `http_client.py` - HTTP клиент для TInvest API
  - `time_utils.py` - утилиты для работы с временем

- **Schemas** (`schemas/`)
  - Типизированные Pydantic схемы для рыночных данных
  - Валидация данных на всех этапах

## Установка

```bash
# Установка зависимостей
pip install -r requirements.txt

# Копирование примера конфигурации
cp .env.example .env

# Редактирование .env файла
nano .env
```

## Конфигурация

Все настройки через переменные окружения (`.env`):

```env
# TInvest API
TINVEST_TOKEN=your_token_here

# PostgreSQL
DB_HOST=localhost
DB_PORT=5432
DB_NAME=market_data
DB_USER=postgres
DB_PASSWORD=your_password

# Настройки загрузки
LOAD_INTERVAL_MINUTES=1
BATCH_SIZE=100
LOG_LEVEL=INFO
```

## Использование

```bash
python main.py
```

Система автоматически:
1. Инициализирует компоненты
2. Создает таблицы в БД (если их нет)
3. Загружает данные по расписанию
4. Сохраняет данные в PostgreSQL

## Добавление нового инструмента

Добавление нового инструмента требует изменения только в `main.py`:

```python
# Добавить в список инструментов
instruments = [
    InstrumentConfig(
        figi="BBG004730N88",
        ticker="SBER",
        class_name="equity",
        name="Сбербанк"
    ),
    # Новый инструмент
    InstrumentConfig(
        figi="BBG000B9XRY4",
        ticker="GAZP",
        class_name="equity",
        name="Газпром"
    )
]
```

## Преимущества архитектуры

1. **Масштабируемость** - добавление новых инструментов без изменения компонентов
2. **Переиспользование** - компоненты независимы и могут использоваться отдельно
3. **Тестируемость** - каждый компонент можно тестировать изолированно
4. **Конфигурируемость** - все параметры через переменные окружения
5. **Типизация** - полная типизация с Pydantic схемами
6. **Чистая архитектура** - четкое разделение ответственности

## Зависимости

- Python 3.9+
- aiohttp - HTTP клиент
- asyncpg - PostgreSQL драйвер
- pydantic - валидация данных
- python-dotenv - работа с .env файлами
